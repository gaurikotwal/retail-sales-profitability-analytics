# Dataset

This project uses the Microsoft AdventureWorks Data Warehouse dataset.

The analysis was based on the following CSV tables:

- FactInternetSales
- DimProduct
- DimProductSubcategory
- DimProductCategory
- DimCustomer
- DimSalesTerritory
- DimDate

The main sales fact table contains 60,398 transaction-line records.

The raw CSV files are not included in this repository. Only the analysis, SQL queries, Power BI report, and dashboard screenshots are published.
